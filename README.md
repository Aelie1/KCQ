
Do you remember Bondage Quest, the game I made in 2016?  This is a remake/sequel/successor to that game.  This time written in TypeScript and with a real UI and not just a hacked apart You-DID-it engine.

Even though it uses a remixed version of the original skunk campaign, I've added five new characters to this one, but you can only pick three to use at once.  It also isn't quite the same campaign, as I've added some new twists to the mix.

If you've never played the original game, it is a tactical combat game where you fight packs of enemies, but the enemy is more interested in binding you up than damaging you.  Every player has one move per turn, and you can use it to attack or escape.  After your turn, the enemies take their turn, and then you keep repeating until the enemies are defeated or your party is captured.

Compared to the original, this one has some big changes:
	
* Enemies expose their intentions for the next round, so you can plan around it
* The dice are gone, and with it, the random escape tables that were in bq1 -- escapes are now deterministic
* The original three characters were replaced with five new characters from my latest novel, Ko-Chan's Chronicles.  You can pick any three you want to fight with.
* The story has been rewritten and expanded from the original game.  It now contains ten total fights and a number of extra cutscenes in between them.
* Battle animations make it easier to follow what is going on as the battle plays out.
* The game has native mobile support, and should be playable on almost any screen size
* Game auto-saving, campaign unlock and progress is also saved -- you don't need to play 5 levels just to have another shot at the queen
* A fully fledged game guide/instruction manual in game along with an encyclopedia/reference for every move, enemy, and binding
* Five difficulties allow you to make the game easier or harder (or much harder) based on your preference
* An expandable architecture which makes it much easier to add new content into the game compared to bq1
